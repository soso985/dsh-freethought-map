## 0. 你是谁、要干什么

把 FreeThought Map 做成 **DSH `web` profile 插件**，挂在官方对话旁边。

- **DSH 是内核**：会话、模型、流式、工具、权限、密钥、多会话，全部用官方能力。  
- **本插件只做外置工作记忆**：把本会话的结算回合投影成链；用户可改挂载、拉联想、改注解、铺满画布。  
- **不是**独立站点，**不是**再做 ChatPanel / OpenAI 兼容请求，**不是** fork 魔改 `@deepseek-ai/dsh`。  
- **不是** dsh-talk-map（会话卡片白板），**不是** dsh-mindmap-chat（官方 fork 列）。  
- **不要把 v0.1 整站（App / AIPanel / aiStore / 全局 CSS / window 快捷键）搬进宿主。** 只复用画布算法与双连线。

## 1. 一句话产品

在 DSH 官方对话旁，边聊边落下可回看、可续问的思路链。  
内容来自 DSH 会话；方向与结构由用户掌控。先链后网。  
**禁止一次生成整张长思维导图。禁止插件替代官方输入框。禁止模型写结构。**

## 2. 工作协议

1. **一次只做一张卡。** 做完停。  
2. **不扩大范围**（趟、脉络自动精简、一次成树、自建聊天、回写/删除 DSH 历史、模型写图）。  
3. **不重写 DSH，不 patch 官方 UI 源码。** 适配只放 `dsh-host.ts` / `dsh-client.ts`。  
4. **红线优先**：拖拽不改 parentId；粉线不参与层级；一条结算回合最多一个投影节点。  
5. 每卡日志必须写：**dsh 版本号 + git commit**（或 npm 精确版本），禁止长期「安装时填写」。  
6. 先问再改未钉死项。  
7. 撤销规则见规格「投影与撤销」——卡 3 之前必须按该节实现，不得拖到卡 7 才想。  
8. 只服务主人自己用顺手。

## 3. 第一版已锁定（含交界）

1. 左图右官方聊；对话可收成窄条/抽屉，图可铺满。  
2. 一个 DSH 会话 = 一张图。Host 为 overlay 写入权威。  
3. 极简落链：user 结算、assistant **成功文本结算** 各一节点。正常回复后焦点跟随 AI；等待期间用户改了焦点则回复不抢焦点。发送时快照父节点。  
4. 删节点 = 只摘图。改字 = 注解（缺字段=原文，空字符串=用户清空）。派生截断标题不写进 overlay。  
5. 点节点 ↔ 官方气泡（**以卡 1 探针证明的 API 为准**）。  
6. 手拉粉线；发送时快照「本轮新粉线」注入；不自动 followup。  
7. 只读工具 `map_get` / `map_search` / `map_overview`；会话身份来自**工具执行上下文**，禁止用浏览器当前打开会话。  
8. 自动投影不可 Ctrl+Z 掉；摘除才是去掉投影。用户操作才进 overlay 历史。跨会话历史隔离。
