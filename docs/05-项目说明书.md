## 1. 项目目标

### 1.1 一句话

在 DSH 的会话旁边长出一张**思路图**：每完成一轮对话就自动多两个节点，用户能把它们重新组织成自己想要的结构，并在下一次发送时把这张图的一小部分作为上下文喂给模型。

### 1.2 要解决的三个问题

| 问题 | 本包的做法 |
| --- | --- |
| 长会话里"我之前想到哪了"找不到 | 每轮自动落链成节点，可跳回官方气泡，可 Ctrl+Z 撤销自己的整理 |
| 结构是模型给的，不是用户给的 | **模型完全只读图**（三个只读工具），结构改动 100% 来自用户操作 |
| 用户的想法与对话脱节 | 发送前把「当前焦点 + 这一轮新拉的自由联想」附进消息（标 `[用户图数据]`） |

### 1.3 明确**不做**（红线，改任何一条必须先问主人）

- ❌ 不做自动成树 / 一键生成思维导图（有**可执行入口**禁词断言）
- ❌ 不做模型写图（只有只读工具，有断言）
- ❌ 不重写 DSH、不 patch 官方 UI 源码
- ❌ 不自建聊天、不回写/删除 DSH 历史
- ❌ 不做"趟 / 脉络自动精简"

### 1.4 完成度（如实）

八张实施卡**全部完成并有验收**，详见 §7。仍然**没做**的：

- **真正的 2D 画布**（现在是链式列表 + 行内操作）→ 计划见 [`04-画布计划.md`](04-画布计划.md)
- **PNG 导出**（依赖画布；目前 `exportDoc('png')` **明确拒绝**并说明原因，不导出空图）

## 3. 入口文件

### 3.1 宿主入口：`package.json` → `exports["."]` → `src/host/index.js`

```js
export const inject = ['storageDomain', 'sessions', 'tools']   // 三个硬依赖
export { buildRemoteContribution }
export function apply(ctx) { … 转发给 storage.js … }
```

**为什么只有 22 行**：入口不做任何逻辑，只做「声明依赖 + 转发」。真正的接线在 `storage.js`，
这样入口文件永远不需要为了改功能而变动。

### 3.2 客户端入口：`package.json` → `exports["./client"]` → `src/client/index.js`

**这是全项目最容易踩死的地方。** 客户端 bundle 是**普通脚本**，不是 ESM：

```js
window.__ModuleLoader__.load({
  id: 'dsh-freethought-map',        // 必须等于包名
  factory(require) {
    const React = require('react')   // 只能从宿主模块表取
    …
    return { inject: [...], apply }
  },
})
```

- ❌ 出现任何 `export` / `import` → `SyntaxError: Unexpected token 'export'`，**插件静默死**
- ❌ 不能 `import` 相对模块 → 需要复用的纯函数只能**逐字复制**（有断言防漂移）
- ✅ `verify-package.mjs` 把它当**普通脚本**用 `vm.Script` 解析，并断言无 `import|export`

### 3.3 profile 侧的挂载点：`cordis.patch.yml`

```yaml
- insert:
    - id: freethought-map
      name: dsh-freethought-map
```

必须是 `insert:`（不是覆盖），且**不得带 `disabled: true`**。实测配置树：

```
# == dsh-freethought-map
- id: freethought-map
  name: dsh-freethought-map
```

## 4. 核心模块

### 4.1 `src/overlay/` —— 纯函数层（343 条断言的绝大多数打在这里）

| 模块 | 职责 | 关键不变量 |
| --- | --- | --- |
| `index.js` | 数据模型、`canSetParent`（防环）、`liftTarget`（上提）、`resolveAnnotation`（注解三态）、`applySave`（rev/409） | 过期 save **绝不覆盖权威** |
| `project.js` | 会话事件 → 节点：`isAppendSurfaceEvent` 过滤、按 `sourceRef` 去重、焦点时序、历史补链、幽灵清理 | 替换副本不重复消费；中止（`interrupted`）不建节点；补链**禁用** live focusId |
| `locate.js` | 图→气泡：三级降级选择器、`ambiguous` 如实报告 | **命中多个不盲选**；找不到不静默 |
| | `applySelection`：选中/焦点分离、点空白不清焦点 | `box-select` 分支**形状保留、UI 未启用**（第一版不做多选） |
| `links.js` | 粉线（无向去重）、`pendingLinkIds` 生命周期、快照三字段、注入文案（≤20 条、500 字） | 重试**复用**同一份快照，不重新采样 |
| `inject.js` | `computeInjection`：三态（不适用/无内容/已注入）、`consumeInjectedSnapshot` | 无可注入内容时**绝不塞空消息** |
| `tools.js` | `map_overview` / `map_get` / `map_search`，会话身份取自执行上下文 | 拿不到会话 → **拒绝调用**；无任何写工具 |
| `undo.js` | 手建/改父/摘除/注解/几何 + `History`/`HistoryBySession` | **只逆转用户操作**；**undo 绝不新建节点**（结构上保证） |
| `io.js` | 导入校验、合并（规格 §11 四条）、重建投影、JSON/MD 导出、帮助 | `sessionId` 不符**硬拒绝**；合并**不得删**投影 |

### 4.2 `src/host/storage.js` —— 宿主接线（745 行）

四件事 + 九个端点：

1. **权威存储**：`storageDomain.open()` → 领域 `freethought_map` / 表 `overlays`；
   写回一律走 `table.update(key, fn)` 的**同一个写链槽位**（用户 save 与自动投影共享 rev 序列）
2. **落链**：`ctx.on('session/event')` → `settlementKindOf` 过滤 → `planProjection` → 写回
3. **发送前注入**：`ctx.on('agent/pre-step')` → `await next()` → `computeInjection` → `{...decision, messages}`
4. **只读工具**：`registerReadonlyTools(ctx, …)`

| 端点 | 作用 |
| --- | --- |
| `load` / `save` | 权威读写（`save` 带 `baseRev`，过期返回 conflict） |
| `describe` | 领域/表/服务名（诊断） |
| `events` | 结算事件日志（区分「没收到」与「去重跳过」） |
| `setPendingLinks` | 待注入粉线集合 |
| `injections` | **注入诊断面**：哪一轮注入了什么 |
| `exportDoc` / `importDoc` / `rebuild` | 卡 8 三件事 |

### 4.3 `src/client/index.js` —— 界面（1104 行）

- 席位：`sidebar.right.pane.tab`（keyed/session）+ `ctx.sidebarRight.openTab`
- 样式隔离：所有选择器前缀 `[data-freethought-map-root]`，只用 `--dsw-alias-*` 主题 token
- 键盘隔离：面板内 `Ctrl+Alt+M` 折叠，**不外泄**（实测：内 0→1，外不变）
- 目前的可点元素（8 个）：链行 ×2、导出 JSON/MD、导入、重建投影、帮助、收起

## 5. 技术栈 / 工具

| 层 | 用什么 | 说明 |
| --- | --- | --- |
| 宿主运行时 | DSH `0.1.7-rc.2` + Cordis `4.0.4` | 一切皆插件；`ctx.x` 未声明即抛 |

| 宿主↔客户端 | `ctx.connection.rpc.call('/api', '<ns>/<method>', {args})` | 官方 `RemoteResult` 包装 |
| 验证 | Node `v24.21.0`（宿主自带）+ 11 套自建断言 + CDP 驱动真实 Edge | 无第三方测试框架 |
| 交付 | `gh` / `git`（https，需绕过失效代理） | 两个 GitHub 仓库 |

## 6. 约束条件（全部经过实测，不是推测）

### 6.1 硬约束（违反即静默失效或整个 UI 挂掉）

| # | 约束 | 实证 |
| --- | --- | --- |
| 1 | 客户端 bundle **不得**出现 `import` / `export` | 三次 `SyntaxError: Unexpected token 'export'`；插件静默死 |
| 2 | 宿主 runtime **解析不到任何裸包名** | `zod` / `schemastery` / `@deepseek-ai/*` 全部 `MODULE_NOT_FOUND` |
| 3 | `ctx.x` 对未 `inject` 的 `x` **直接抛** | `cannot get property "x" without inject` |
| 4 | `apply()` 里抛错 = **整个 Web UI 拒绝加载** | 实测「Failed to load plugins」 |
| 5 | **不得猜 `inject` 服务名** | 必须先找到 `provide("<name>")` 或 `super(ctx, "<name>")` |
| 6 | 存储单元名必须匹配 `/^[a-z][a-z0-9_]*$/` | `freethought-map`（带连字符）被拒 → 改 `freethought_map` |
| 7 | 客户端 bundle 不能 `import` 相对模块 | 纯函数只能逐字复制（有防漂移断言） |

### 6.2 环境约束

| 约束 | 说明 |
| --- | --- |
| dsh CLI 在 `app.asar` 里 | 必须先 `npx @electron/asar extract`；纯 Node 读 asar 会 ENOENT |
| profile 的 `node_modules` 大部分是死链接 | 指向不存在的 `E:\Harness\DSH Desktop\…` |
| `pwsh`（PowerShell 7）**不在 PATH** | 只有 Windows PowerShell 5.1；`.ps1` 必须存成 **UTF-8 BOM**，否则中文全乱 |
| 本机 git 配的代理 `127.0.0.1:6450` **已失效** | `git push` 需 `-c http.proxy= -c https.proxy=`（**不改全局配置**） |
| 官方气泡定位只能靠内部 DOM | `[data-chat-node-key]`，key = `` `${kind.length}:${kind}${id}` ``；**非公开承诺** |

### 6.3 产品约束（来自规格）

- 换行 = `Shift+Enter`；官方发送是**唯一**发送入口
- 不整图 fit，只"轻推视口"
- 拖动只记被拖节点的 position 前后，**禁止整份 doc 快照**
- 撤销历史按会话隔离、栈深 50、刷新后可丢（帮助里已写明）
- 工具输出必须短（概览 ≤60 行、搜索 ≤20 条、正文 ≤500 字）
