# FreeThought Map · DSH 插件版 · 实施计划（任务卡）

> 一次一张卡。卡 1 探针失败 → 停，不要开始卡 3。  
> 每卡 `docs/HOST.md` 或开发日志写明 **dsh 版本 + commit（或 npm 精确版）**。  
> 禁止自建聊天、禁止魔改 DSH 源码、禁止把 v0.1 整 App 搬进宿主。

---

## 总顺序

```
卡 0 仓与文档边界
 → 卡 1 扩展点探针 + 布局 + 样式/快捷键隔离 + 构建加载
 → 卡 2 Host 权威存储协议（含 409、切会话、重连）
 → 卡 3 身份/去重/落链/焦点时序/补链/投影撤销边界
 → 卡 4 双向定位（只用卡 1 已证明的 API）
 → 卡 5 粉线 + 发送快照上下文（只用卡 1 已证明的发送前钩子）

 → 卡 7 手建、改父、摘除上提、注解、用户撤销
 → 卡 8 重建投影、JSON 导入合并、三种导出、帮助；检查可执行入口而非全文 grep
```

## 卡 0 · 仓与文档

**做：**

- **决定并落地仓库：** 独立插件包 `dsh-freethought-map`（默认）。不要把插件发布成对 v0.1 整仓的 `dsh plugin add`。  
- 规格放 `docs/`（本四份 + 空的 `HOST.md` 模板：版本/commit/探针表）。  
- README 两节写死：  
  - 「v0.1 独立站原型（已实现）」→ 链到 soso985/freethought-map  
  - 「DSH 插件（规划/实现中）」→ 安装命令、红线、与 talk-map / mindmap-chat 区别  
- 填 HOST.md 表头：拟验证的 dsh 版本（开工当天 `npm ls` / git rev-parse，**禁止留「安装时填写」**）。

**不做：** 功能代码（可建空 package.json）。  
**验收：** 两节 README 不会让人把原型仓当插件装；HOST.md 已有具体版本字符串。

## 卡 1 · 探针 + 空壳布局 + 隔离

**目标：** 证明扩展点；左图右聊可收；样式与快捷键不污染宿主。

**做：**

- 最小 Cordis 插件装进 web profile。  
- `probe.ts` 对 §8 五项各写「调用的符号、结果、失败表现」。写入 HOST.md。  
- 布局：左图画布占位、右官方对话、收/展；宽度与收展持久化（可先 local 再卡 2 迁 Host）。  
- 根节点隔离 CSS；快捷键只在根内。确认打开官方设置页、发送一条官方消息，外观与快捷键正常。  
- 构建：add 插件后刷新无 error。

**不做：** 落链、存储权威、工具。  
**验收：**

| ID | 期望 |
| --- | --- |
| D1-0 | HOST.md 有 dsh version+commit，五项探针各一行可行/不可行 |
| D1-1 | 当前会话左侧有插件根 |
| D1-2 | 收对话图变宽，仍能用官方输入 |
| D1-3 | 刷新保持布局 |
| D1-4 | 设置页可用；官方输入框 Enter 仍发送 |
| D1-5 | 若布局或点击或发送前注入不可行：已停并问主人，而不是假装以后再修 |

布局不可行时 **本卡结束状态 = 阻塞**，不得进入卡 3。

## 卡 3 · 落链（含身份、焦点、补链、sync 非撤销）

**做：** 规格 §6.3–6.5、§7。Host 或带 rev 的 applyProjection。发送快照父节点。AI 不抢已改焦点。历史补链按时间线。100 用户消息窗口。去重与重连 no-op。  
**不做：** 粉线注入、只读工具、手建（可暂不暴露按钮）。  
**验收：**

| ID | 期望 |
| --- | --- |
| D3-1 | 未改焦点时链为 U1→A1→U2→A2 |
| D3-2 | 等待 A1 时点到 F，再发 U2：A1 仍挂 U1；U2 挂 F |
| D3-3 | 排队两条发送：各用发送时父节点，不都挂到最后焦点 |
| D3-4 | 同一结算重放不复制节点 |
| D3-5 | 打开旧会话补链不把旧节点挂到当前焦点 |
| D3-6 | 拖动中途 A 到达；撤销拖动后 A 节点仍在 |
| D3-7 | Ctrl+Z 不能去掉刚投影的节点；摘除可以 |
| D3-8 | 无「生成导图」**可点击入口**（工具栏/命令/工具注册） |

## 卡 5 · 粉线 + 发送快照

**做：** 粉线；pendingLinkIds；§10.3 快照/消费/重试/发送后删线；注入标 `[用户图数据]`。不 followup。无发送前钩子则按卡 1 降级（仅工具可见，本卡只做粉线存储）。  
**验收：** 拉线不增 turn 节点；干等无自动回复；下一句含快照联想（或已记录降级）；发送后删线仍注入快照；发送前删线则不注入。

## 卡 6 · 只读工具

**做：** 三工具 + 限额 + `[用户图数据]`。sessionId 来自执行上下文。测：浏览器看着会话 B，会话 A 的 agent 调工具只能看到 A。  
**不做：** 写工具。  
**验收：** overview/get/search 只读；overlay 无变化；错会话拒绝或返回 A 而非 B。

---

## 卡 7 · 用户结构操作

**做：** 手建节点；手动改 parentId（Tree 边，防环）；摘除+上提（§6.6 唯一规则）；注解（缺字段 vs ""）；用户撤销栈（§7）；width/height 若拖缩放则保存。  
**验收：** 摘除对话还在、补链不复活 hidden；清空 title 显示空而非原文；撤销摘除恢复；改父成环拒绝；历史不跨会话。

---

## 卡 8 · 导入导出与收口

**做：** 重建投影按钮（§6.5）；JSON 导入校验+合并（§11）；导出 JSON / Markdown / PNG；帮助短文。  
**禁词检查（不要全文 grep 文档）：** 检查 **可执行入口**：工具注册表、命令面板、按钮 label、agent 可调工具名。允许文档/帮助出现「禁止一键生成思维导图」字样。失败标准：存在会执行成树的按钮或 write 工具。  
**验收：** 导入错 sessionId 拒绝；导入可撤销；官方发送仍是唯一发送；设置页仍好。
